# Audio Copilot IPP

## Visão Geral

O Audio Copilot IPP é um assistente inteligente desenvolvido para auxiliar na operação da mesa digital Soundcraft Ui24R utilizada na Igreja Presbiteriana de Piracicaba.

Seu objetivo é funcionar como um operador virtual de áudio, capaz de:

- Ler todas as configurações da mesa.
- Identificar problemas.
- Sugerir melhorias.
- Aplicar configurações automaticamente.
- Monitorar o culto em tempo real.
- Gerar relatório após o culto.

No futuro o sistema utilizará Inteligência Artificial para tomar decisões semelhantes às de um operador humano experiente.

---

# Objetivos

## Curto prazo

- Ler todas as configurações da Ui24R.
- Mostrar todos os canais.
- Mostrar EQ.
- Mostrar Compressor.
- Mostrar Gate.
- Mostrar Auxiliares.
- Mostrar FX.
- Salvar snapshots.

---

## Médio prazo

- Aplicar automaticamente configurações de EQ.
- Configurar canais conforme os instrumentos.
- Detectar clipping.
- Detectar excesso de ganho.
- Detectar microfonia.
- Detectar canais desligados.
- Detectar cabos desconectados.

---

## Longo prazo

Criar um operador virtual capaz de acompanhar todo o culto.

O operador virtual deverá:

- ouvir o ambiente
- acompanhar o volume
- acompanhar feedback
- acompanhar equilíbrio da banda
- acompanhar inteligibilidade da voz
- sugerir correções
- aplicar correções automaticamente

# Filosofia do projeto

O operador humano deixa de ficar preocupado com regulagens técnicas e passa apenas a supervisionar o sistema.

O Audio Copilot fará a maior parte do trabalho automaticamente.
